# 小说编辑器

专业的桌面小说创作工具。

## 安装

打包后的安装程序位于 `release` 目录：
- `小说编辑器 Setup 1.0.0.exe` - 安装程序
- `win-unpacked\小说编辑器.exe` - 直接运行版本

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build

# 打包为 Windows 应用
npm run electron:build:win
```

## 技术栈

React + Vite + Electron + TypeScript + Tailwind CSS
